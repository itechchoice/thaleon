# thaleon

Landing page + macOS releases for **thaleon-agent** — a chat-first desktop
copilot for Malaysian Unit Trust Consultants.

- **Landing page**: published via GitHub Pages (`index.html` at repo root) →
  https://itechchoice.github.io/thaleon/
- **Download**: the latest signed + notarized macOS build is attached to the
  newest [GitHub Release](https://github.com/itechchoice/thaleon/releases/latest)
  as `thaleon-agent.dmg` (Apple Silicon only).

The download button links to the stable latest-release URL:
`https://github.com/itechchoice/thaleon/releases/latest/download/thaleon-agent.dmg`
