Windows: what to do if SmartScreen warns "Unknown publisher"

The Windows installer is currently not Authenticode-signed (we're working on it). On first launch, Windows may show "Windows protected your PC".

Click More info, then Run anyway. After the install completes, subsequent launches don't trigger this warning.

If your IT department enforces signed-only software via AppLocker or WDAC, you may not be able to install this build — let your team know and we'll prioritise code signing.

Mac note
The Mac build runs on Apple Silicon only (M1, M2, M3, M4…). Intel-based Macs are not supported yet. Not sure which you have? Click the Apple menu → About This Mac and look for “Apple M…” under Chip.

What it does

Fund research & market desk

Look up any fund's NAV, fees, and KPIs, or ask about SC / BNM / Bursa news and FX — answered with cited, dated sources.

Client management

Search clients, create or edit profiles from a KYC document, and record or adjust their holdings — in plain language.

Portfolios & X-Ray

Build investment proposals, X-Ray a client's portfolio for risk and exposure, and review retirement plans with what-ifs.

Pitch packs

Generate a compliant, client-ready recommendation — screened against your firm's model, guard rails, and advisor controls — and export to PDF.

Installing

Mac

  1. Download thaleon-agent.dmg using the button above.
  2. Open the .dmg and drag thaleon-agent into your Applications folder.
  3. Launch it from Applications. The app is signed and notarized by Apple, so it opens normally — no security warnings.

Windows

  1. Download thaleon-agent-setup.exe using the button above.
  2. Run the installer. SmartScreen may warn that the publisher is unknown — click More info → Run anyway.
  3. Follow the installer (you can choose the install path). After install, launch from the Start Menu or desktop shortcut.
